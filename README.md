 Employee Salary Prediction Using Machine Learning
 Overview
Income classification system trained on real-world census data to predict whether an individual earns above or below a salary threshold. Built as the primary capstone deliverable of the Edunet Foundation internship.
 Technical Environment
Python, Scikit-learn, Pandas, NumPy, Google Colab
Roles & Responsibilities
- Built an income classification pipeline from raw census data through model deployment. 
- Applied data cleaning, outlier handling, and preprocessing to prepare the dataset for training.  
- Compared multiple classification algorithms; achieved 76.87% accuracy and 0.77 weighted F1-score on a test set of 13,606 records.
